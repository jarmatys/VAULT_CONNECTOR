# VaultConnector

Ask your Obsidian vault from Claude on your phone: no computer left running, no Docker, and only the folders you
choose, read-only.

VaultConnector is open source under the [GNU AGPL-3.0](LICENSE). You can self-host it for free, or use the hosted
version. The project is at an early stage; the repository bootstrap is in progress.

Obsidian is a trademark of its owner. VaultConnector is an independent project and is not affiliated with or endorsed
by Obsidian.
